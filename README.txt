MASS 12 — local hypertrophy tracker

1. Open index.html in a browser.
2. Data is stored locally in that browser using localStorage.
3. On iPhone, the easiest initial approach is to host this file on a simple static host or run it from a computer on your network; Apple Health integration requires a native iOS layer and is intentionally deferred.
4. V1 includes: 12-week phase logic, Home/PureGym workouts, set logging, RIR, automatic exercise-specific rest timer, workout history, manual daily weight and 7-day averages.

Important: browser data can be cleared. A later version should add JSON/CSV backup/export before relying on it as the only long-term training record.
